Lightning Pong 1.0.0 - Archive Edition (Levels 1-3)

On Windows, double-click PLAY-WINDOWS.cmd. It starts a local server and opens the game in your browser. Keep its window open while playing. On macOS or Linux, serve this folder with a local HTTP server and open /app/index.html. Do not open the HTML file directly; browser module security prevents it from loading that way.

W/S, arrow keys, drag, or touch move Player 1. P pauses. Progress saves in this browser on this device, separately from the full game. This edition contains three original Xen Arcade stage tracks, five arena backgrounds, and two circuit UI images. It includes no unrelated recordings or QA tools.
