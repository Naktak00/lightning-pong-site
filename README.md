# Lightning Pong Site

Static GitHub Pages site for Lightning Pong v0.2 Closed Alpha.

Pages:

- `index.html`
- `privacy.html`
- `tester-guide.html`
- `qa.html`
- `contact.html`

Recommended GitHub Pages setup:

1. Create a public repository, for example `lightning-pong-site`.
2. Upload the contents of this `site` folder to the repository root.
3. In GitHub, open Settings > Pages.
4. Set source to `Deploy from a branch`.
5. Choose branch `main` and folder `/root`.
6. Save and wait for GitHub Pages to publish.

Expected public URL:

`https://<github-username>.github.io/lightning-pong-site/`

Expected privacy policy URL:

`https://<github-username>.github.io/lightning-pong-site/privacy.html`
